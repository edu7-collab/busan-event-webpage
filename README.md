# 부산 시민 마라톤 대회

행사 홍보용 단일 HTML 페이지입니다. HTML과 CSS는 `event_homepage.html`에 포함되어 있습니다.

- 행사 일시: 2026년 12월 12일(토) 09:00
- 안내 장소: 광안리 해수욕장
- 정확한 참가 신청 링크: 별도 공지
- 제공되지 않은 행사 정보: 미정으로 표시

## GitHub Pages 배포

저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 설정합니다.

`main` 브랜치에 변경 내용을 올리면 `.github/workflows/pages.yml`이 행사 페이지를 자동으로 배포합니다. 게시 주소의 첫 화면과 `event_homepage.html` 경로에서 같은 페이지를 볼 수 있습니다.

배포 파일은 `event_homepage.html`에서 생성됩니다. 참고자료와 기획 문서는 로컬 프로젝트에 보관합니다.
