# 매일 업무 체크 대시보드

`event_homepage.html`을 Edge 또는 Chrome에서 열어 사용합니다. 인터넷 연결 없이 사용할 수 있는 단일 HTML 파일입니다.

## 사용 방법

- 날짜를 선택하고 5개 업무의 미시작·진행 중·완료 버튼을 누릅니다.
- 세부 체크를 펼치면 업무별 확인 항목, AI 활용 방안, 진행 메모를 볼 수 있습니다.
- 일부 확인 항목을 체크하면 진행 중, 모두 체크하면 완료로 바뀝니다.
- 완료 버튼은 확인 항목을 모두 체크합니다. 미시작 버튼은 해당 업무의 체크를 해제합니다. 메모는 유지됩니다.
- 완료된 업무를 진행 중으로 되돌리면 세부 체크가 해제됩니다.
- 기록은 날짜별로 이 브라우저의 localStorage에 자동 저장됩니다. 새 날짜에는 미시작 상태로 시작합니다.
- 기록 백업으로 모든 날짜의 JSON 파일을 저장하고, 백업 불러오기로 복원할 수 있습니다. 겹치는 날짜를 덮어쓰기 전 확인합니다.

## 저장 범위

다른 PC나 브라우저와 자동 동기화되지 않습니다. 브라우저 저장 데이터를 삭제하거나 HTML 파일의 위치를 변경하면 기록에 접근하지 못할 수 있으므로 필요한 기록은 백업하세요. 저장이 차단되면 경고가 표시됩니다.

이 페이지는 개인 업무 진행 기록용이며 실제 전자결재, 온북, 민원 시스템이나 외부 AI와 연결되지 않습니다. 세부 확인 항목은 제공된 업무 내용을 바탕으로 제안한 항목입니다.

## 보관한 기존 파일

기존 부산 시민 마라톤 행사 페이지는 `outputs/event_homepage_before_dashboard.html`에 원본 그대로 보관했습니다.

GitHub Pages 주소: https://edu7-collab.github.io/busan-event-webpage/

`main` 브랜치의 변경 내용을 원격 저장소로 올리면 기존 GitHub Actions 워크플로가 이 대시보드를 배포합니다. 웹페이지는 공개되지만 업무 체크 기록과 메모는 서버로 전송되지 않으며, 접속한 브라우저에만 저장됩니다. 로컬 파일에서 사용한 기록은 공개 주소로 자동 이전되지 않습니다. 필요한 경우 로컬 화면에서 백업한 JSON 파일을 공개 주소에서 불러오세요.
